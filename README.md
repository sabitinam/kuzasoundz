# 🎵 KUZA Soundz

> **Keep Underground Alive.**
Chicago's home for Black, African, and Diaspora music—celebrating Amapiano, Afrohouse, 3Step, Gqom, Chicago house, jazz, blues, and soul.

---

## 🚀 About the Project
KUZA is a community-first web platform designed to highlight events, stream live DJ mixes, and connect the underground music scene in Chicago.

## 🛠️ Tech Stack
* **Framework:** Next.js (React) ⚛️
* **Styling:** Tailwind CSS 🎨
* **Language:** TypeScript 📘
